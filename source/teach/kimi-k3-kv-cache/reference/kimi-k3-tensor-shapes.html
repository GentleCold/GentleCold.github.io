Block AttnRes

sources [T,R,7168] score[t,r] = q_l^T RMSNorm(sources[t,r]) a[t,:] = Softmax(score[t,:]) [R] h_l[t] = Σ_r a[t,r] sources[t,r] [7168]

R 是深度来源数，不是序列长度。vLLM forward buffer 为 [T,8,7168]；attention 前和 MLP 前各有独立 score projection。它在当前 forward 内存在，不跨生成 token 持久化。
