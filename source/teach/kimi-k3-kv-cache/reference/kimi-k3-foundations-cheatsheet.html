Kimi K3 基础概念速查

先用这张表建立词汇，再回到架构图。每个词都回答“它是什么”，而不是先回答“它怎么优化”。

词直觉在 K3 中的角色
Dense FFN每个 token 都经过同一组大参数变换。提供所有 token 都需要的通用能力。
MoE把一个大 FFN 拆成许多专家，由 router 选择少数几个。扩大参数容量，同时控制每个 token 的计算量。
Latent把高维表示压到更窄的中间空间。让 routed experts 在较小宽度上做专门变换。
LatentMoE共享专家走完整宽度，路由专家先降维、在 latent 宽度工作，再升维。让 896 个专家、每 token 激活 16 个变得更可扩展。
普通 Attention当前 query 直接查看历史 token 的 K/V。全局内容访问强，但历史 K/V 会随序列长度增长。
KDA把历史持续折叠进一个递归 state，当前 query 读取这个 state。用线性/递归路径承担长上下文 token mixing。
Gated MLA保存压缩 latent，需要时重建 K/V 做全局 attention。周期性补充不受限的全局内容交互。

主来源：Kimi K3 Technical Report，第 2 节。术语解释先追求正确心智模型，具体 kernel layout 以后再学。
