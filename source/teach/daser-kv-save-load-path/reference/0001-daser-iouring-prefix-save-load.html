Teach / DaseR KV Save/Load Path

DaseR iouring + prefix save/load 速查

两条路径方向相反，但共享同一个控制面：server 分配 slot，worker 只导出 staging，commit 后才进入 prefix index。

Save / Store

1. Scheduler lookup miss. get_num_new_matched_tokens() 查询 prefix；miss 时 PrefixReuseStrategy.prepare_store() 生成 PendingStore。
2. Prefix slot allocation. update_state_after_alloc() 记录 vLLM block IDs；PrefixReuseStrategy.allocate_store() 为每个未缓存 slot 调 alloc_chunks()。
3. Metadata handoff. build_connector_meta() 在 slot 已计算后发布 ReqStoreSpec。
4. Finished-request staging. wait_for_save() 暂存 commit plan；get_finished() 在 request finished 且 KV blocks 仍有效时调用 _submit_finished_save()。
5. KV cache -> staging. _stage_store_batch() 复制 selected block KV 到 slot-major CUDA staging，并记录 CUDA event。
6. staging -> server. _write_cuda_buffer() 导出 CUDA IPC handle，调用 transfer_store。
7. server -> L1 -> L2. IPC server 过滤 stale spans；TieredIOUringTransferLayer.store_bytes() 先写 L1 pinned slice，再异步调 io_uring 写 L2。
8. Commit. batch store 完成后 commit_chunks()；ServerCore.commit_chunk() 插入 PrefixHashIndex。

Load / Restore

1. Scheduler lookup hit. PrefixHashIndex.lookup() 从 prompt 开头按 rolling keys 连续命中 committed slots。
2. Map target blocks. update_state_after_alloc() 把 hit chunk 的 target token window 修剪到 vLLM 分配的 block IDs。
3. Metadata handoff. build_connector_meta() 发布 ReqLoadSpec。
4. L1/L2 -> staging. worker 在 start_load_kv() 分批申请 staging，调用 server transfer_load；transfer layer 先查 L1，miss 再从 L2 读入并 promote 到 L1。
5. staging -> KV cache. copy_staging_to_kv_cache() 把 slot-major staging 写回 vLLM KV blocks，必要时应用 scale / RoPE delta。

Prefix Mode Rules

  • key 不是整段 prompt hash；每个 slot key 是 H(prev_key, block_tokens_i)。
  • save 时每个未缓存 slot 是一个 synthetic request id：req:store:<slot_i>。
  • commit 之前 metadata 存在，但 lookup 不可见。
  • L1 只缓存 byte ranges；持久 index 保存的是 committed chunk metadata，不保存 L1 状态。
